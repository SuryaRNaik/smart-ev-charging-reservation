\## Working Rules



1\. Pull the latest changes from `main` before starting new work.

2\. Avoid editing the same files simultaneously without coordinating.

3\. Use separate branches for substantial features where practical.

4\. Never commit `.env.local`, passwords, database credentials, or other secrets.

5\. Use only dummy data for demonstrations. Do not integrate real payment processing or real charging hardware.

6\. Push changes regularly and use descriptive commit messages.
