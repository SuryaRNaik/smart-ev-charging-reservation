# Smart EV Charging Station Reservation System

A DBMS Level 3 mini project developed by Sriniket Deeduvanu and Surya R Naik.

## Overview

A web-based system for managing EV charging stations, charging-point reservations, and payment records.

## Technology Stack

- **Frontend and Backend:** Next.js
- **Relational Database:** MySQL
- **NoSQL Database:** MongoDB Atlas
- **Version Control:** Git and GitHub

## Planned Features

- User registration and login
- EV charging station and charging-point listing
- Charging reservation management
- Simulated payment records
- Admin management interface
- Reservation activity logging
- SQL reports and advanced database concepts

## Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/)
- npm, which is installed automatically with Node.js
- Git
- MySQL
- A MongoDB Atlas account

### 1. Clone the repository

Open Command Prompt (CMD) and run:

```cmd
git clone https://github.com/sriniket-d/smart-ev-charging-reservation.git
```

### 2. Navigate to the project folder

```cmd
cd smart-ev-charging-reservation
```

### 3. Install dependencies

```cmd
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root directory.

Add the required database connection settings when they are implemented. Never commit database passwords, API keys, or other secrets to GitHub.

### 5. Start the development server

```cmd
npm run dev
```

### 6. Open the application

Open [http://localhost:3000](http://localhost:3000) in your browser.

The development server must remain running in CMD while you use the application.

### 7. Stop the development server

Press `Ctrl + C` in the CMD window running the server.

## Development

The main application pages are located in the `app/` directory.

Changes to application files are reflected in the browser while the development server is running.
